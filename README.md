Digital Logic Gate Classifier

Project Description

This project uses Machine Learning and Natural Language Processing concepts to classify digital logic gates based on their natural-language descriptions.

Technologies Used

- Python
- Google Colab
- Machine Learning

Project Features

- Accepts natural-language descriptions of logic gate operations.
- Predicts the corresponding logic gate.
- Displays the predicted output.

Sample Predictions

Input Description| Predicted Gate
Output is high only when both inputs are high| AND
Output is high only when both inputs are low| NOR

How to Run

1. Open the Jupyter Notebook.
2. Run all cells in Google Colab.
3. Enter a logic gate description.
4. View the predicted output.
